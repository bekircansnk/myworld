## 2024-07-28 - React Cascading Re-renders from Unmemoized Parent Dependencies
**Learning:** In React components that re-render frequently (e.g. `DashboardWidgets` due to a clock interval), computing an array directly in the render body (like `const mainTasks = tasks.filter(...)`) creates a new array reference on every render. If this unmemoized array is then used as a dependency in subsequent `useMemo` hooks (like `weeklyProgressStats`, `calendarDays`, `recentTasks`), it completely breaks those memoizations, causing them to recompute on every single tick, leading to compounding performance degradation.
**Action:** Always memoize derived array or object states with `useMemo` if they are going to be passed down to child components or used as dependencies in other hooks, especially in frequently rendering components.
