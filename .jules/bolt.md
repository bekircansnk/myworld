## 2024-07-30 - Missing useMemo and Hoisting in Array Filters
**Learning:** Found multiple instances where array `.filter()` loops containing expensive operations (like string `.toLowerCase()`) and missing `useMemo` were placed directly in the render path. Because these filters often depended on controlled text inputs (e.g., search queries), typing triggered re-renders that recalculated the filter and re-ran the O(N) string operations on every keystroke, leading to O(N * M) operations where N is the array length and M is the keystroke count. This compounds performance degradation in React.
**Action:** When filtering arrays in React based on text inputs, always wrap the filtered array calculation in `useMemo`. Furthermore, hoist any repetitive operations that do not change per-item (such as calling `.toLowerCase()` on the search query) outside the `.filter` loop to reduce their complexity from O(N) to O(1).
