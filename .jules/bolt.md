## 2025-01-16 - Precompute Hash Maps for Event Calendars
**Learning:** In the `CalendarPage.tsx` code, `.filter()` logic was used iteratively inside `days.map` and `HOURS.map` calls to find events that belong to a specific date and time. Since the calendar might display 30 days and 24 hours, running `events.filter()` repeatedly on a potentially large dataset of tasks and events produces an O(N*M) performance bottleneck, needlessly burning CPU cycles and potentially causing UI lag on mobile devices when navigating months or rendering lots of tasks.
**Action:** Always avoid calling `.filter()` on the main dataset inside `.map()` loops when organizing items into groups. Instead, construct a precomputed hash map (`Map` or `Record`) in a single O(N) pass wrapped in `React.useMemo()`. This reduces the rendering time to O(N + M) and ensures the lookup operations are instantaneous.
