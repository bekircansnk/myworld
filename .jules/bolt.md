## 2024-05-19 - Unnecessary O(N) Array Operations on Frequent Renders
**Learning:** React components containing text inputs connected to local state (like `aiInput` in `DashboardWidgets.tsx`) will re-render on every keystroke. If expensive array operations like `.filter()` or `.map()` are placed directly in the component body without memoization, they will recalculate O(N) times on every single key press, leading to noticeable UI lag on large arrays.
**Action:** Always wrap derived array filtering or mapping operations (like sorting tasks or calculating completion rates) in a `React.useMemo` hook with the appropriate dependency array (e.g., `[tasks]`). This ensures the calculation only runs when the underlying data changes, not during generic component re-renders triggered by state updates.
