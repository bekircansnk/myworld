## 2026-08-20 - Premature optimization in small datasets\n**Learning:** In a codebase, changing an O(N*M) array iteration into an O(N) map logic for trivially small subsets (like a 4-item array) causes complexity for zero measurable impact, making it a bad micro-optimization.\n**Action:** Avoid complex data structures replacements for bounded iterations over very small data sizes; prioritize readability.\n\n## 2026-08-20 - Redundant String Allocations in React Render Loops\n**Learning:** Array `.filter()` computations that perform inline `query.toLowerCase()` inside the iteration loop will reallocate the lowercase string thousands of times during keystroke renders, wasting CPU and memory.\n**Action:** Always hoist static variables like `query.toLowerCase()` outside of `.filter()` or `.map()` iterators.
