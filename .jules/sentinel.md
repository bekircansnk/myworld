## 2024-06-25 - [Path Traversal in AI Analysis Report Upload]
**Vulnerability:** Found a Path Traversal vulnerability in `app/backend/app/routers/ads/reports.py` during file upload. The `file_name` extracted from `file.filename` is directly used in `os.path.join(upload_dir, f"{uuid.uuid4().hex}_{file_name}")`. If a malicious user supplies a filename like `../../../../../etc/passwd`, the file will be saved outside of the intended `/tmp/venus_ai_uploads` directory.
**Learning:** `os.path.basename` on the server operating system will only parse filenames using the OS separator (e.g. `/` on Linux), which can leave `\` characters unsanitized. While it protects against basic directory traversal payloads like `../../../`, we should be mindful of cross-platform constraints. Additionally, FastAPI `UploadFile` handles empty filenames by making `file.filename` `None`.
**Prevention:** Always extract base filenames using `os.path.basename(file.filename)` with a fallback for `None` values, or consider using libraries like `werkzeug.utils.secure_filename` to prevent path traversal via malicious upload filenames.
