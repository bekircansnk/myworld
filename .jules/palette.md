## 2026-08-24 - ARIA Labels for Icon-Only Navigation Buttons\n**Learning:** The application's top and bottom navigation bars contain several interactive, icon-only buttons (like notifications, theme toggle, and menu closing) that lacked descriptive text for screen readers. This is a common pattern that reduces accessibility for users relying on assistive tech.\n**Action:** Ensure all interactive elements that do not display visible text include contextually appropriate `aria-label` attributes, maintaining the app's primary language (Turkish).
