## 2024-05-19 - ARIA labels for TopNavbar icon-only buttons
**Learning:** Icon-only interactive elements (like the theme toggle, user profile menu, and notification bell) in `TopNavbar.tsx` were missing ARIA labels, making their purpose ambiguous for screen reader users. The application relies on Lucide React icons inside standard `<button>` tags for these common actions. Providing descriptive, localized ARIA labels improves screen reader compatibility without altering the visual design.
**Action:** Always verify that buttons containing only icons and no text content have appropriate `aria-label` attributes to ensure they are fully accessible to assistive technologies. For multi-state buttons like theme toggles, ensure the `aria-label` correctly reflects the action of the current state.
