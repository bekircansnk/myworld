## 2024-05-24 - Missing ARIA labels on Icon-Only Buttons
**Learning:** This application's UI heavily utilizes icon-only buttons (especially Lucide icons within generic `<button>` or `<Button>` tags) in core navigation components like `Sidebar.tsx`. These buttons consistently lack descriptive `aria-label` attributes and rely solely on visual cues or `title` attributes, resulting in a poor experience for screen reader users and violating accessibility guidelines. Furthermore, they often lack explicit `focus-visible` styling, hindering keyboard navigation.
**Action:** When implementing or reviewing UI components, specifically check all icon-only interactive elements and enforce the addition of localized `aria-label`s and clear `focus-visible` states to ensure robust accessibility.
